# 2. Understanding Budget Types

We will support two types of budgets.

## 2.1 Category-wise Budget

A category-wise budget applies to a specific expense category.

Example:

```text
Food Budget: ₹8,000

Expenses:
    Groceries       ₹2,000
    Restaurant      ₹1,500
    Snacks          ₹500

Total Spent:        ₹4,000

Remaining:          ₹4,000
```

The user has spent 50% of their food budget.

## 2.2 Overall Budget

An overall budget applies to all expenses during a particular month.

Example:

```text
Overall Monthly Budget: ₹25,000

Food:               ₹4,000
Shopping:           ₹3,000
Transportation:     ₹2,000
Bills:               ₹5,000

Total Spent:        ₹14,000

Remaining:          ₹11,000
```

The user has spent 56% of their overall budget.

### Difference

| Category-wise Budget | Overall Budget |
|---|---|
| Applies to one category | Applies to all expense categories |
| Requires category ID | Category ID is NULL |
| Tracks specific spending | Tracks total spending |

**Important:** The overall budget is a separate spending limit. It does not add to the category budgets. The same expense can count toward both an overall budget and its corresponding category budget.

# 3. Database Design

We previously designed a `budgets` table.

Let's review the structure.

| Column | Data Type | Description |
|---|---|---|
| id | BIGINT | Primary key |
| user_id | BIGINT | Budget owner |
| category_id | BIGINT NULL | Category ID |
| amount | DECIMAL(12,2) | Budget amount |
| month | TINYINT | Budget month |
| year | SMALLINT | Budget year |
| created_at | DATETIME | Creation timestamp |
| updated_at | DATETIME | Last update |

### Example records

| ID | User ID | Category ID | Amount | Month | Year |
|---:|---:|---:|---:|---:|---:|
| 1 | 10 | 1 | 8000 | 11 | 2026 |
| 2 | 10 | 2 | 5000 | 11 | 2026 |
| 3 | 10 | NULL | 25000 | 11 | 2026 |

Here:

- Record 1 represents the Food budget.
- Record 2 represents the Shopping budget.
- Record 3 represents the overall November 2026 budget.

### Why do we use NULL for category_id?

Because an overall budget does not belong to a specific category.

For category-wise budgets:

```text
category_id = 1
```

For overall budgets:

```text
category_id = NULL
```

# 4. Important Database Constraint

We must prevent users from creating duplicate budgets.

For example, this should not be allowed:

| User ID | Category ID | Month | Year |
|---:|---:|---:|---:|
| 10 | 1 | 11 | 2026 |
| 10 | 1 | 11 | 2026 |

The user should only have one budget for the same category and month.

We can create a unique constraint:

```sql
CREATE UNIQUE INDEX unique_user_category_budget
ON budgets(user_id, category_id, year, month);
```

However, there is an important MySQL detail:

**MySQL permits multiple NULL values in a normal unique index.**

Therefore, the above constraint does not prevent multiple overall budgets where `category_id` is NULL.

### Recommended solution: Generated column

Create a generated column that replaces NULL with a reserved value.

```sql
ALTER TABLE budgets
ADD COLUMN category_key BIGINT
GENERATED ALWAYS AS (
    COALESCE(category_id, 0)
) STORED;
```

Now create the unique index:

```sql
CREATE UNIQUE INDEX unique_user_monthly_budget
ON budgets(user_id, category_key, year, month);
```

Because valid category IDs are positive, zero can represent an overall budget.

This enforces uniqueness for both:

- Category-wise budgets.
- Overall budgets.

For production, include this constraint in a Sequelize migration rather than manually changing the database.

```javascript
const { DataTypes } = require("sequelize");

module.exports = (sequelize) => {

    const Budget = sequelize.define("Budget", {

        id: {
            type: DataTypes.BIGINT,
            primaryKey: true,
            autoIncrement: true
        },

        userId: {
            type: DataTypes.BIGINT,
            allowNull: false,
            field: "user_id"
        },

        categoryId: {
            type: DataTypes.BIGINT,
            allowNull: true,
            field: "category_id"
        },

        amount: {
            type: DataTypes.DECIMAL(12, 2),
            allowNull: false
        },

        month: {
            type: DataTypes.TINYINT,
            allowNull: false
        },

        year: {
            type: DataTypes.SMALLINT,
            allowNull: false
        }

    }, {

        tableName: "budgets",

        timestamps: true,

        underscored: true

    });

    return Budget;

};
```

# 8. Budget Repository

The repository will handle database operations.

Create:

```text
src/modules/budgets/budget.repository.js
```

```javascript
const { Op } = require("sequelize");

const {
    Budget,
    Expense,
    Category
} = require("../../database/models");


class BudgetRepository {

    // Create budget
    async create(data, transaction = null) {

        return await Budget.create(data, {
            transaction
        });

    }


    // Find budget by ID and owner
    async findById(id, userId) {

        return await Budget.findOne({

            where: {
                id,
                userId
            },

            include: [
                {
                    model: Category,
                    as: "category",
                    attributes: ["id", "name", "type"]
                }
            ]

        });

    }


    // Find budget for a particular month
    async findByPeriod(userId, month, year) {

        return await Budget.findAll({

            where: {
                userId,
                month,
                year
            },

            include: [
                {
                    model: Category,
                    as: "category",
                    attributes: ["id", "name", "type"]
                }
            ],

            order: [["id", "ASC"]]

        });

    }


    // Find matching budget
    async findByCategoryAndPeriod(
        userId,
        categoryId,
        month,
        year
    ) {

        const categoryCondition =
            categoryId === null
                ? { categoryId: null }
                : { categoryId };

        return await Budget.findOne({

            where: {

                userId,

                month,

                year,

                ...categoryCondition

            }

        });

    }


    // Get expense totals grouped by category
    async getExpenseTotals(userId, startDate, endDate) {

        return await Expense.findAll({

            attributes: [

                "categoryId",

                [
                    require("sequelize").fn(
                        "SUM",
                        require("sequelize").col("amount")
                    ),
                    "totalSpent"
                ]

            ],

            where: {

                userId,

                expenseDate: {

                    [Op.gte]: startDate,

                    [Op.lte]: endDate

                }

            },

            group: ["categoryId"],

            raw: true

        });

    }


    // Get total expenses for the month
    async getTotalExpenses(userId, startDate, endDate) {

        return await Expense.sum("amount", {

            where: {

                userId,

                expenseDate: {

                    [Op.gte]: startDate,

                    [Op.lte]: endDate

                }

            }

        });

    }


    // Update budget
    async update(id, userId, data) {

        const [updatedRows] = await Budget.update(data, {

            where: {
                id,
                userId
            }

        });

        return updatedRows;

    }


    // Delete budget
    async delete(id, userId) {

        return await Budget.destroy({

            where: {
                id,
                userId
            }

        });

    }


}

module.exports = new BudgetRepository();
```

## Important Concepts

### 8.1 What is SUM()?

Suppose our expenses table contains:

| ID | User ID | Category ID | Amount |
|---:|---:|---:|---:|
| 1 | 10 | 1 | 2,000 |
| 2 | 10 | 1 | 1,500 |
| 3 | 10 | 2 | 3,000 |
| 4 | 10 | 2 | 500 |

We can calculate total spending using:

```sql
SELECT SUM(amount)
FROM expenses
WHERE user_id = 10;
```

Result:

```text
7000.00
```

### 8.2 What is GROUP BY?

Suppose we want total spending for each category.

```sql
SELECT
    category_id,
    SUM(amount) AS total_spent
FROM expenses
WHERE user_id = 10
GROUP BY category_id;
```

Result:

| Category ID | Total Spent |
|---:|---:|
| 1 | 3,500 |
| 2 | 3,500 |

`GROUP BY` groups records having the same category ID.

Then `SUM()` calculates the total for each group.

This is useful for dashboards and budget calculations.

# 9. Budget Service

The service layer will implement our budget-related business logic.

Create:

```text
src/modules/budgets/budget.service.js
```

```javascript
const { Op } = require("sequelize");

const budgetRepository = require("./budget.repository");

const {
    Category
} = require("../../database/models");

const ApiError = require("../../utils/ApiError");


class BudgetService {


    // Validate expense category
    async validateCategory(categoryId, userId) {

        if (categoryId === null) {
            return null;
        }

        const category = await Category.findOne({

            where: {

                id: categoryId,

                type: "expense",

                [Op.or]: [
                    { userId },
                    { userId: null }
                ]

            }

        });


        if (!category) {

            throw new ApiError(
                400,
                "Invalid expense category"
            );

        }

        return category;

    }


    // Get monthly date range
    getMonthDateRange(month, year) {

        const startDate =
            `${year}-${String(month).padStart(2, "0")}-01`;

        const lastDay = new Date(
            Date.UTC(year, month, 0)
        ).getUTCDate();

        const endDate =
            `${year}-${String(month).padStart(2, "0")}-${lastDay}`;

        return {
            startDate,
            endDate
        };

    }


    // Create budget
    async createBudget(userId, data) {

        await this.validateCategory(
            data.categoryId,
            userId
        );


        const existingBudget =
            await budgetRepository.findByCategoryAndPeriod(

                userId,

                data.categoryId,

                data.month,

                data.year

            );


        if (existingBudget) {

            throw new ApiError(
                409,
                "Budget already exists for this period"
            );

        }


        try {

            return await budgetRepository.create({

                userId,

                categoryId: data.categoryId,

                amount: data.amount,

                month: data.month,

                year: data.year

            });

        } catch (error) {

            if (
                error.name === "SequelizeUniqueConstraintError"
            ) {

                throw new ApiError(
                    409,
                    "Budget already exists for this period"
                );

            }

            throw error;

        }

    }


    // Get all budgets with spending information
    async getAllBudgets(userId, month, year) {

        const budgets = await budgetRepository.findByPeriod(
            userId,
            month,
            year
        );


        const {
            startDate,
            endDate
        } = this.getMonthDateRange(month, year);


        const expenseTotals =
            await budgetRepository.getExpenseTotals(
                userId,
                startDate,
                endDate
            );


        const totalExpenses =
            await budgetRepository.getTotalExpenses(
                userId,
                startDate,
                endDate
            );


        const categoryTotals = new Map(

            expenseTotals.map(item => [

                String(item.categoryId),

                item.totalSpent || "0"

            ])

        );


        const results = budgets.map(budget => {

            const isOverallBudget =
                budget.categoryId === null;

            const spentAmount = isOverallBudget

                ? (totalExpenses || "0")

                : (
                    categoryTotals.get(
                        String(budget.categoryId)
                    ) || "0"
                );


            const budgetAmount = budget.amount;


            const spent = Number(spentAmount);

            const allocated = Number(budgetAmount);


            const remaining = allocated - spent;


            const utilization = allocated > 0

                ? (spent / allocated) * 100

                : 0;


            let status = "normal";


            if (utilization >= 100) {

                status = "exceeded";

            } else if (utilization >= 80) {

                status = "warning";

            }


            return {

                id: budget.id,

                category: budget.category,

                budgetAmount,

                spentAmount,

                remainingAmount: remaining.toFixed(2),

                utilizationPercentage:
                    utilization.toFixed(2),

                status

            };

        });


        return {

            period: {
                month,
                year
            },

            budgets: results

        };

    }


    // Get budget by ID
    async getBudgetById(budgetId, userId) {

        const budget = await budgetRepository.findById(
            budgetId,
            userId
        );


        if (!budget) {

            throw new ApiError(
                404,
                "Budget not found"
            );

        }


        return budget;

    }


    // Update budget
    async updateBudget(budgetId, userId, data) {

        const updatedRows = await budgetRepository.update(

            budgetId,

            userId,

            data

        );


        if (updatedRows === 0) {

            throw new ApiError(
                404,
                "Budget not found"
            );

        }


        return await budgetRepository.findById(
            budgetId,
            userId
        );

    }


    // Delete budget
    async deleteBudget(budgetId, userId) {

        const deletedRows = await budgetRepository.delete(

            budgetId,

            userId

        );


        if (deletedRows === 0) {

            throw new ApiError(
                404,
                "Budget not found"
            );

        }


        return {

            message: "Budget deleted successfully"

        };

    }

}


module.exports = new BudgetService();
```

### Important production correction: Financial calculations

The example uses:

```javascript
const spent = Number(spentAmount);
const allocated = Number(budgetAmount);
```

This is acceptable for illustrating the calculation, but it is **not suitable for precise financial arithmetic**.

For production, use a decimal library such as `decimal.js`.

For example:

```javascript
const Decimal = require("decimal.js");

const spent = new Decimal(spentAmount || "0");

const allocated = new Decimal(budgetAmount);

const remaining = allocated.minus(spent);

const utilization = spent
    .dividedBy(allocated)
    .times(100);

console.log(remaining.toFixed(2));
console.log(utilization.toFixed(2));
```

Install:

```bash
npm install decimal.js
```

Also note that SQL `SUM(DECIMAL)` returns an exact decimal result, but the Node.js driver may represent it as a string.

### Understanding Budget Utilization

Formula:

```text
Budget Utilization =
(Spent Amount / Budget Amount) × 100
```

Example:

```text
Budget Amount = ₹10,000

Spent Amount = ₹8,000

Utilization = (8000 / 10000) × 100

Utilization = 80%
```

We use the following status rules:

| Utilization | Status |
|---|---|
| Below 80% | Normal |
| 80% to below 100% | Warning |
| 100% or above | Exceeded |

These thresholds are business rules. They can be changed according to application requirements.

```javascript
const budgetService = require("./budget.service");


class BudgetController {


    // Create budget
    async createBudget(req, res) {

            success: true,

    // Update budget

        const budget = await budgetService.updateBudget(

            req.params.id,

            req.user.id,

            req.body

        );


        res.status(200).json({

            success: true,

            message: "Budget updated successfully",

            data: budget

        });

    // Delete budget

            req.params.id,

        res.status(200).json({

            success: true,

            ...result

        });

    }

}
```

# 14. Understanding Budget Calculations

Let's take a practical example.

Suppose the user has created the following budgets:

| Category | Budget |
|---|---:|
| Food | ₹8,000 |
| Shopping | ₹5,000 |
| Transportation | ₹3,000 |
| Overall | ₹25,000 |

And their expenses are:

| Category | Expense |
|---|---:|
| Food | ₹2,000 |
| Food | ₹1,500 |
| Shopping | ₹3,000 |
| Transportation | ₹1,000 |
| Transportation | ₹500 |

### Step 1: Calculate category-wise spending

Food:

```text
2000 + 1500 = 3500
```

Shopping:

```text
3000
```

Transportation:

```text
1000 + 500 = 1500
```

### Step 2: Calculate remaining budget

Formula:

```text
Remaining Budget = Budget Amount - Spent Amount
```

| Category | Budget | Spent | Remaining |
|---|---:|---:|---:|
| Food | ₹8,000 | ₹3,500 | ₹4,500 |
| Shopping | ₹5,000 | ₹3,000 | ₹2,000 |
| Transportation | ₹3,000 | ₹1,500 | ₹1,500 |

### Step 3: Calculate utilization

Formula:

```text
Utilization = (Spent / Budget) × 100
```

| Category | Utilization |
|---|---:|
| Food | 43.75% |
| Shopping | 60.00% |
| Transportation | 50.00% |

### Step 4: Calculate overall spending

```text
Total Spending =
3500 + 3000 + 1500

Total Spending = ₹8,000
```

Overall budget:

```text
₹25,000
```

Remaining:

```text
₹25,000 - ₹8,000 = ₹17,000
```

Utilization:

```text
(8000 / 25000) × 100 = 32%
```

# 15. Important Production Considerations

Our implementation demonstrates the core functionality. Before deploying it, consider these improvements.

| Area | Production Recommendation |
|---|---|
| Duplicate budgets | Enforce database unique constraints |
| Overall budget | Handle NULL uniqueness correctly |
| Financial calculations | Use decimal-safe arithmetic |
| Category validation | Verify ownership and category type |
| Authorization | Scope every query by user ID |
| Budget updates | Validate affected-row count |
| Notifications | Trigger alerts when thresholds are crossed |
| Historical records | Decide how deleted budgets are retained |
| Performance | Use aggregate queries and suitable indexes |

### Important: Budget calculations and deleted expenses

If you implement soft deletion for expenses, your aggregate queries must exclude deleted records.

For Sequelize paranoid models, normal model queries generally exclude soft-deleted rows automatically.

### Important: Budget exceeded does not mean spending is blocked

Suppose:

```text
Budget = ₹5,000
Spent = ₹6,000
```

The application should report:

```text
Budget exceeded by ₹1,000
```

It should not automatically reject the expense.

Budget management is generally a tracking and notification feature, not a financial transaction restriction.

# 16. Interview Questions and Answers

### Q1. What is budget management?

Budget management involves defining spending limits and tracking actual expenses against those limits.

### Q2. What is a category-wise budget?

A budget assigned to a specific expense category.

### Q3. What is an overall budget?

A spending limit covering all expense categories for a particular period.

### Q4. What is budget utilization?

The percentage of the budget already consumed.

### Q5. How do you calculate remaining budget?

Remaining budget equals budget amount minus actual spending.

### Q6. What is SQL SUM()?

`SUM()` is an aggregate function that calculates the total of a numeric column.

### Q7. What is GROUP BY?

`GROUP BY` groups rows sharing the same values so aggregate calculations can be performed for each group.

### Q8. What is an aggregate query?

A query that calculates summary information using functions such as SUM, COUNT, AVG, MIN, or MAX.

### Q9. Why do we use DECIMAL for financial calculations?

DECIMAL provides exact decimal representation, making it suitable for financial values.

### Q10. Why is a unique constraint important?

It prevents duplicate records from being inserted into the database.

### Q11. Why can MySQL unique indexes allow multiple NULL values?

MySQL treats NULL as distinct for unique-index purposes, so multiple rows containing NULL in an indexed column can be permitted.

### Q12. How can we prevent duplicate overall budgets?

Use a generated column that converts NULL category IDs into a reserved value and include that column in a unique index.

### Q13. What is the difference between WHERE and HAVING?

`WHERE` filters rows before grouping. `HAVING` filters groups after aggregation.

### Q14. What is a database transaction?

A transaction groups database operations into a single logical unit that can be committed or rolled back.

### Q15. How can we implement budget notifications?

Calculate budget utilization and trigger notifications when configured thresholds are crossed.
